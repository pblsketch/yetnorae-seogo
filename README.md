# 옛 노래 서고

**만든이**: 박준일 (온양여자고등학교 국어 교사)

고등학교 공통국어2 고전시가 단원을 위한 **갈래 판별 학습 게임**입니다.
학생은 먹안개에 잠긴 서고를 물려받은 견습 사서가 되어, 흩어진 옛 노래의 **생김새를 손으로 재고** 향가·고려가요·시조·가사·사설시조 가운데 제자리를 찾아 꽂습니다.

> 학습 목표: 학생은 처음 보는 옛 노래도 생김새를 보고 어떤 갈래인지, 누가 불렀을지 짐작할 수 있게 된다.

수능 고전시가에는 교과서 밖 작품이 자주 나옵니다. 그래서 작품을 외우게 하기보다 갈래의 생김새를 재고 판단하는 일을 되풀이하게 만들었습니다. 형식 분석이 게임의 핵심 조작이고, 퀴즈 관문은 따로 없습니다.

- 별도 설치나 계정 없이 브라우저에서 실행합니다. **가로 화면 전용**이며 휴대폰(가로)·크롬북·태블릿·PC를 대상으로 만들었습니다. 3D를 쓸 수 없는 기기에서는 같은 규칙의 2D 그림 판으로 끝까지 갑니다.
- 학생 한 명이 혼자 합니다. **이어폰**을 쓰는 것을 전제로 하고, 소리를 낼 수 없으면 빗금 모드로 끝까지 갈 수 있습니다.
- 점수·등급·순위·시간 제한·게임 오버가 없습니다. 틀려도, 도움을 받아도 끝까지 갈 수 있습니다.
- 진행 기록은 **그 브라우저에만** 저장됩니다(서버로 보내지 않음). 바깥 주소로 요청하지 않습니다.

## 실행하기

| 방법 | 설명 |
| --- | --- |
| 내 컴퓨터에서 | 저장소 폴더에서 `python -m http.server 8770`을 실행하고 `http://127.0.0.1:8770`을 연다 |
| 파일로 | `index.html`을 바로 열면 브라우저가 모듈과 자산 읽기를 막아 실행되지 않는다. 위처럼 정적 서버로 연다 |
| 공개 주소 | 아직 없다. 교사가 글 확인 문서를 확인하고 모든 노래가 확인을 마친 뒤 공개한다 |

- 빌드나 패키지 설치가 필요 없습니다(정적 웹 페이지, ES 모듈, Three.js는 `vendor/three/`에 들어 있음).
- 장면이나 관을 건너뛰는 주소 인자, 선생님용 입구는 **없습니다**. 학생은 누구나 입구부터 정해진 순서로 갑니다.
- 처음 켜는 기기에서는 기록을 고른 뒤 이어폰 안내와 박자 맞추기(종소리 여덟 번 따라 치기)를 합니다. 설정에서 다시 맞출 수 있습니다.

## 구성과 수업 배분

한 판(관 하나)이 약 15분, 게임 전체가 약 100분이 되도록 만들었습니다. 아래 시간은 **수업 배분안**이며 학생 대상 실측값이 아닙니다.

| 차례 | 장면 | 하는 일 | 배분 |
| --- | --- | --- | --- |
| 0 | 입구 | 편지와 선대 사서의 목소리로 미션을 받고, 첫 노래 「태산이 높다 하되」로 접기 → 두드리기 → 계단 오르기를 익힌다 | 10분 |
| 1 | 향가관 | 탑(4구·8구·10구 층)에 향가를 꽂는다. 작품 방 「제망매가」 | 15분 |
| 2 | 고려가요관 | 줄지은 방, 후렴 고리 걸기. 작품 방 「정석가」 | 15분 |
| 3 | 시조관 | 3층 정자, 계단 오르기. 작품 방 「십 년을 경영하야」 | 15분 |
| 4 | 가사관 | 끝없는 회랑, 걷기(네 박 한 걸음). 작품 방 「상춘곡」 | 15분 |
| 5 | 사설시조관 | 늘어난 가운데 층, 연타로 풀기. 작품 방 「님이 오마 하거늘」 | 15분 |
| 6 | 보스전 「서고의 밤」 | 수첩 없이 낯선 노래 다섯 편 판별과 '누가 불렀을까', 엉킨 낭송에서 갈래가 바뀌는 곳 짚기, 좀 대왕이 삼킨 첫 노래 되찾기 | 10~15분 |
| 7 | 엔딩 | 선대 사서의 귀환, 가객 행렬, 나의 노래 한 줄 짓기와 근거 고르기, 마지막 카드 | 5분 |

**판별 수업에 나누어 쓰는 예(45분 차시 기준)**

| 차시 | 범위 | 비고 |
| --- | --- | --- |
| 1차시 | 입구 + 향가관 + 고려가요관 | 입구에서 재는 법을 익힌다. 판을 마치면 다음 관 문틈으로 그 관의 소리가 새어 나와 다음 차시를 예고한다 |
| 2차시 | 시조관 + 가사관 + 사설시조관 | 시조와 사설시조를 같은 차시에 견주어 볼 수 있다 |
| 3차시 앞부분 | 보스전 + 엔딩 | 보스전이 곧 형성 평가 자리다(점수 없이 카드에 기록만). 남은 시간은 결과 카드로 디브리핑 |

- 판마다 결과 카드(PNG)를 내려받을 수 있습니다. 판 카드에는 꽂은 칸 노래, 그 갈래의 개념 상태(연필/먹), 작품 방의 기록, 덤을 했는지가 담깁니다. 마지막 카드에는 보스전 낯선 노래 다섯 편의 '처음에 맞혔는지'·'일지 도움을 받았는지'·'누가 불렀을까를 맞혔는지'와 엔딩의 한 줄이 담깁니다. 내려받지 못했거나 파일을 잃어버렸으면 시작 화면의 이름 기록 목록에서 '결과 카드'를 눌러 언제든 다시 받을 수 있습니다. 다시 받는 카드는 그때의 기록으로 다시 그려지므로, 판을 마친 뒤 덤을 했다면 그것도 담깁니다.
- 빨리 끝낸 학생은 마친 관의 **덤 칸**(노래 세 편 더)을 합니다. 덤은 진도나 다음 관 조건에 들어가지 않아 교실 안 속도 차이를 흡수합니다.
- 기록은 의미 있는 행동(꽂기, 판정, 방 완료, 재기 완료)마다 저장되므로 차시가 끝나 창을 닫아도 다음 차시에 그 자리에서 이어 갑니다.

## 학생이 어려워하는 점과 게임 장치

| 어려워하는 점 | 게임 장치 |
| --- | --- |
| 처음 보는 노래의 갈래를 알아보지 못한다 | **재기**: 노래를 잡으면 두루마리에서 단위 경계를 접고(단위 수), 낭송에 맞춰 음보마다 장구를 두드린다(단위마다 음보 수). 감정서에는 갈래 이름 칸이 없고, 학생이 꽂는 자리로 답한다. 보스전에서는 『분류 수첩』 없이 교과서 밖 노래와 수능 출제 지문을 판별한다 |
| 향가의 구 수와 10구체의 짜임 | 향가관은 4구·8구·10구 층이 쌓인 **탑**이고, 고유 동작 **'아아' 문 열기**로 마지막 무리 첫머리의 감탄사를 찾는다 |
| 고려가요의 분연과 후렴 | 똑같은 방이 줄지은 고려가요관에서 **후렴 고리 걸기**로 연마다 되풀이되는 구절을 잇는다 |
| 시조의 종장 첫 음보 세 글자 | 3층 정자의 종장으로 오르는 첫 계단이 세 칸이다. **계단 오르기**로 글자마다 한 칸씩 오른다 |
| 가사의 4음보 연속과 정해지지 않은 길이 | 끝이 안 보이는 회랑을 네 박마다 한 걸음씩 **걷는다**. 세 장에서 멈추는지, 계속 이어지는지가 증거다 |
| 시조와 사설시조를 헷갈린다 | 사설시조관은 가운데 층만 늘어난 정자다. **연타로 풀기**로 늘어난 중장을 체감한다. 보스전에서 이 둘은 마지막에 붙어 나온다 |
| 누가 불렀는지(향유층)를 갈래와 잇지 못한다 | 칸이 묶이면 **가객**이 종이 인형으로 나타나 한 소절을 부르고, 기념품 카드에 향유층 한 줄을 남긴다. 보스전의 '누가 불렀을까', 엔딩의 가객 행렬(시대 순)로 이어진다 |
| 옛 표기가 읽히지 않는다 | 두루마리를 누를 때마다 **원문 → 오늘 소리 → 풀이**가 바뀐다. 모든 노래에 AI 낭송이 있다 |
| 개념을 외우기만 하고 근거로 쓰지 못한다 | 사서 일지의 개념은 판정을 통과한 노래가 한 편이면 **연필**, 두 편 이상이면 **먹**이 된다. 같은 관에서 세 번 틀리면 수첩의 관련 줄이 반짝인다. 엔딩에서는 먹이 된 개념 가운데 하나를 근거로 골라야 한 줄을 꽂을 수 있다 |

작품 방의 해석(「제망매가」의 마지막, 「십 년을 경영하야」의 세 칸 배치 등)은 채점하지 않고 '해석'으로 표시합니다. 원작의 줄거리와 결말은 바꾸지 않았습니다. 설화에 바탕한 장면에는 '전해지는 이야기' 표시를 붙였습니다.

## 저장 방식

- 그 브라우저의 로컬 저장소(localStorage)에만 둡니다. 저장 열쇠는 `yetnorae-seogo-v1` 하나이고, 서버로 보내지 않습니다. 다른 기기로 옮기는 기능은 없습니다.
- **이름별 기록**: 시작 화면에서 이름(1~12자, 별명 가능)을 고르면 이어 하고, 새 이름을 쓰면 새 기록이 생깁니다. 같은 이름을 새로 쓰면 이어 할지 묻습니다. 기록마다 견습 사서의 모습(둘 가운데 하나)을 고릅니다.
- 기록 보호(비밀번호)는 없어 누구나 목록에서 이름을 골라 이어 할 수 있습니다. 지우기는 확인을 한 번 거치고, 그 기록의 결과 카드 자료도 함께 지워집니다.
- 같은 기록을 두 창에서 열면 나중에 저장한 쪽이 남습니다.
- 사생활 보호 모드처럼 저장할 수 없는 환경이면 그 사실을 알리고 이번 창에서만 진행합니다.
- 설정(소리 크기, 빗금 모드, 글자 크기 3단계, 움직임 줄이기, 박자 보정)은 그 기기의 모든 이름 기록에 함께 쓰입니다.

## 글과 출처

| 노래 | 원문 | 풀이·해독 |
| --- | --- | --- |
| 교과서에 실린 노래(「제망매가」, 「십 년을 경영하야」, 「상춘곡」) | 고등학교 공통국어2 교과서 수록본 그대로 | 교과서 그대로(교과서에 없는 오늘 소리와 일부 풀이는 제작진이 씀) |
| 문학 교과서 수록 작품(「찬기파랑가」, 「정석가」, 「사미인곡」, 「나모도 바히 돌도」) | 지금은 옛 문헌·공개 자료의 글. 교과서 파일이 오면 수록본으로 바꾼다 | 학자의 해독·풀이를 출처와 함께, 또는 제작진 |
| 교과서 밖 노래 | 옛 문헌(『삼국유사』, 『악학궤범』, 『악장가사』, 『시용향악보』, 『청구영언』, 『가곡원류』, 『송강가사』, 『노계집』 등)의 원문을 공개된 전사본·영인본으로 옮김 | 향가는 교과서 향가와 같은 학자인 김완진의 해독(『향가해독법연구』), 「동동」·「정읍사」 등은 출처에 적은 학자의 풀이, 나머지는 제작진 |
| 수능 출제작(「갑민가」, 「창 밖에 워석버석」, 「이 시름 저 시름」) | 한국교육과정평가원이 공개한 문제지의 출제 지문과 발췌 범위 | 제작진(문제지 각주가 있으면 따름) |

- 노래마다 출처(`citation`)와 확인 상태(`verification`)를 데이터에 적었습니다. 교과서 밖 글은 모두 `pending`(교사 확인 전)이고, 교사가 대조해 확인하면 `verified`로 바꿉니다. 「상춘곡」은 교과서 대목 뒤에 『불우헌집』 원문(위키문헌)을 이어 붙였고, 그 부분은 화면에 '교과서 밖 원문'으로 표시합니다.
- 게임 안 **출처 화면**(시작 화면의 '출처')에 교과서 수록본, 해독·풀이의 학자와 책, 옛 문헌, 국립국악원 음원(공공누리 출처 문구), AI 음성 서비스와 요금제, 그림 생성 방식, 글꼴, 프로그램을 모두 적었습니다. 목록은 노래 데이터와 자산 목록에서 그때그때 만듭니다.
- 공개 전 교사 확인용 **글 확인 문서**: [`docs/글-확인-문서.md`](docs/글-확인-문서.md). 게임이 새로 쓴 글 전부, 확인할 노래의 원문·해독·풀이와 출처, 낭송 목소리 배정과 먼저 들어 볼 낭송, 보스전과 엔딩 화면 그림을 관별로 모았습니다.

## 소리·목소리·그림·글꼴

- **낭송**: AI 합성 음성입니다. Fish Audio의 **유료 API 요금제**(상업 이용 가능, 모델 s2.1-pro)로 만들었습니다. 목소리는 실제 사람을 본뜨지 않고 이 게임을 위해 글 설명만으로 설계한 둘입니다. 차분한 30대 여성 목소리가 여성 화자가 분명한 13편을, 따뜻하고 낮은 50대 남성 목소리가 나머지 32편을 읽습니다(승인 기록 `docs/approvals.md`, 배정 `tools/voice/voices.json`). 줄 단위로 읽힌 뒤 음보마다 잘라 박자에 맞춰 잇습니다(향가는 구마다 한 조각). 노래마다 빠르기가 다릅니다.
- **배경음과 장구 소리**: 국립국악원이 공공누리 제1유형으로 개방한 「국악기 디지털 음원」의 악구를 잘라 잇거나 다듬었습니다. 관마다 곡이 다르고, 두드리는 소리는 장구입니다. 효과음 일부는 직접 합성했습니다. 곡과 악구 번호는 [`assets/audio/CREDITS.md`](assets/audio/CREDITS.md)에 있습니다.
- **그림**: Codex CLI의 이미지 생성(gpt-image)으로 이 게임을 위해 만들었습니다. 승인한 화풍(한지를 오려 겹친 종이 인형, 가는 먹선, 한지 미색·먹·먹회색 바탕에 단청색을 조금)에 맞추었고, 그림 안에 글자를 넣지 않았습니다. 프롬프트는 `tools/art/prompts/`, 생성 원본은 저장소에 올리지 않습니다(`assets/raw/`).
- **글꼴**: Noto Serif KR에서 게임에 쓰인 글자만 남긴 부분 글꼴 `Yetnorae Text`(SIL OFL 1.1, `assets/fonts/OFL.txt`). 옛한글 자모를 한 글자로 모으는 기능을 그대로 남겼습니다. Noto Serif KR에 없는 드문 향찰 이체자 몇 자는 기기 글꼴로 그려집니다.
- **프로그램**: Three.js 0.186.1(MIT License).
- 모든 자산의 출처와 사용권은 자산 목록 `assets/manifest.json`(조각은 `assets/manifest.parts/`)에 있습니다.

## 내용 고치기

학습 내용은 모두 `js/data/`의 데이터 파일에 있어 코드를 몰라도 고칠 수 있습니다. 데이터 형식은 [`js/data/README.md`](js/data/README.md)가 기준입니다.

| 파일 | 내용 |
| --- | --- |
| `js/data/songs/<갈래>.js` | 노래(원문·오늘 소리·풀이, 해독, 출처, 가객, 기념품, 형식 표시) |
| `js/data/notebook-<갈래>.js` | 『분류 수첩』 갈래 설명 |
| `js/data/concepts.js` | 사서 일지의 개념 문장, 향유층 무리 |
| `js/data/rooms-<갈래>.js` | 작품 방의 글과 해석 문장 |
| `js/data/story.js`, `js/data/boss-text.js` | 편지·대사·단서·엔딩 글, 보스전 글 |
| `js/data/remix.js` | 보스 2단계 리믹스 조각 |
| `js/data/credits.js` | 출처 화면의 글 |

글을 고친 뒤에는 아래를 다시 돌립니다.

- 새 글자가 생겼으면 글꼴: `python tools/fonts/build_fonts.py`(원본 글꼴은 `tools/fonts_src/`, 저장소 밖)
- 글 확인 문서: `node tools/text/review-doc.mjs`, 화면 그림: `node tools/text/review-shots.mjs`
- 교과서 대조(교과서 추출본이 있는 제작 기기에서만): `node tools/text/compare-textbook.mjs`
- 자산 목록 합치기: `node tools/manifest/build.mjs`

## 점검

점검 묶음은 Node, Playwright, 설치된 Chrome, 로컬 임의 포트 서버를 씁니다.

```sh
cd tests && npm ci      # 처음 한 번
cd ..
node tests/run-all.mjs  # 전체 점검, 0으로 끝나야 완료
```

- 점검 하나만: `node tests/check-<이름>.mjs`(예: `check-data`, `check-rights`, `check-fonts`, `check-credits`, `check-review-doc`).
- 데이터(노래 형식, 출처와 확인 상태, 개념의 먹 가능성, 기념품), 권리(출판사 이름 없음, 바깥 요청 없음, 자산 출처), 진행 엔진, 관과 작품 방, 보스, 이야기 흐름, 결과 카드, 낭송 조각, 배경음, 글꼴, 출처 화면, 글 확인 문서를 확인합니다. 점검마다 실제 실패를 잡는지 보는 음성 사례가 들어 있습니다.
- 점검 도구는 특정 장면을 볼 때만 로컬 저장소에 기록을 넣습니다. 제품에는 그런 입구가 없습니다.
