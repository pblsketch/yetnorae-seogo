# 보안과 권리

이 게임에는 서버도 계정도 없다. 그래서 지킬 것은 '침입'보다 **학생 기록이 기기 밖으로 나가지 않는 것**, **저장소에 들어가면 안 되는 이름·파일·비밀이 들어가지 않는 것**, **사용권이 분명한 자산만 쓰는 것**이다.

## 1. 지키는 것

| 지키는 것 | 어디에 있나 | 어떻게 다루나 |
| --- | --- | --- |
| 학생 이름(별명)과 진행 기록 | 학생 브라우저의 로컬 저장소 열쇠 `yetnorae-seogo-v1` | 기기 밖으로 보내지 않는다. 바깥 요청, 분석 도구, 서버 전송이 없다 |
| 결과 카드 PNG(이름이 그려짐) | 학생이 내려받은 기기 | 게임이 따로 보관하지 않는다. 기록을 지우면 다시 그릴 자료도 사라진다 |
| 교과서 출판사 이름 | 저장소 밖 `design/`(기획 문서, 교과서 파일 이름) | 저장소에 올라가는 파일·커밋 글·브랜치 이름 어디에도 들어가지 않는다 |
| 교과서 PDF와 추출본 | `design/source/`(저장소 밖), 형제 저장소 | 커밋하지 않는다. 교과서 대조 도구만 읽는다 |
| Fish Audio API 키 | 제작 기기의 `%LOCALAPPDATA%/yetnorae/fish.key` 한 곳 | 아래 '자격 증명' |
| Codex 로그인 토큰 | 제작 기기의 `~/.codex/auth.json` | 그림 도구가 임시 폴더로 잠깐 복사하고 끝나면 지운다. 저장소에 넣지 않는다 |
| 생성 원본(그림 PNG, 목소리 기준 음성, 낭송 응답, 국악 원본 WAV, 원본 글꼴) | `assets/raw/`, `tools/voice_cache/`, `tools/music_src/`, `tools/fonts_src/` | 커밋하지 않는다(`.gitignore`). 목소리 기준 음성 백업은 지우면 같은 목소리를 다시 만들 수 없으므로 지우지 않는다 |

## 2. 들어가기(인증)

인증이 없다. 시작 화면에서 이름 기록을 고르는 것이 곧 들어가는 일이다. 비밀번호를 두지 않은 것은 사용자의 결정이고, 기기 관리는 교실에 맡긴다.

| 단계 | 정상 | 실패 경로 |
| --- | --- | --- |
| 1. 저장소 읽기 | 로컬 저장소에서 문서를 읽는다 | 저장소를 쓸 수 없음(사생활 보호 모드, 보안 오류) → 알림 한 번, 이번 창 메모리로만 진행 |
| 2. 문서 해석 | 버전 1이면 그대로 읽고 약속 밖 값을 버린다 | JSON이 깨짐 → 새로 시작하고 다음 저장에서 덮어씀. 옮길 수 없는 옛 버전 → 같음. **더 새 버전** → 덮어쓰지 않고 이번 창 메모리로만 진행(새 버전 기록을 지키려고) |
| 3. 이름 고르기 | 목록의 이름을 누르면 그 기록으로 이어 간다 | — (누구나 아무 이름이나 고를 수 있다) |
| 4. 새 이름 | 1~12자, 기기 안에서 처음 쓰는 이름이면 새 기록 | 빈 이름·13자 이상 → 만들지 않음. 같은 이름 → 만들지 않고 이어 할지 묻기 |
| 5. 저장 | 의미 있는 행동마다 문서 전체를 쓴다 | 저장소 가득 참·쓸 수 없음 → 알림 한 번, 메모리로 계속 |

## 3. 누가 무엇을 할 수 있나

| 하는 일 | 학생(기기 앞의 누구나) | 교사 | 점검 도구 | 제작자(사람·에이전트) |
| --- | --- | --- | --- | --- |
| 이름 기록 만들기·고르기·이어 하기 | 된다(어느 이름이든) | 학생과 같다 | 페이지 안에서 실제 입력으로 | — |
| 이름 기록 지우기 | 확인 한 번 뒤에 된다(어느 이름이든) | 같다 | 실제 입력으로 | — |
| 관 순서 건너뛰기, 장면 바로 열기, 정답 보기 | **안 된다** | **안 된다**(교사 기능 없음) | **안 된다**(제품 안에서는) | 제품에 그런 길을 만들 수 없다 |
| 진행 상태 넣기 | 안 된다 | 안 된다 | 페이지를 열기 **전에** 로컬 저장소에 기록을 넣는 방식만(`tests/lib/browser.mjs`의 `seed`, `tools/text/review-shots.mjs`) | 점검 도구 안에서만 |
| 서고 완성 뒤 판정·보스·엔딩 기록 바꾸기 | 안 된다 | 안 된다 | — | — |
| 바깥 주소로 요청 | 게임이 하지 않는다 | — | 요청을 모아 하나라도 있으면 실패 | 게임 코드에 넣을 수 없다 |
| Fish Audio API 쓰기 | — | — | — | 제작 기기에서 `build_voice.py`로만, `--max-usd` 안에서 |
| GitHub 저장소 만들기·올리기·Pages 켜기 | — | — | — | 사용자 승인 뒤에만(지금은 공개 전) |
| 패키지·프로그램 설치, 바깥 파일 내려받기, 유료 서비스 결제 | — | — | — | 할 때마다 사용자 승인 뒤에만 |

명시적으로 허락하지 않는 것:
- 주소 인자(`?…`, `#…`)로 진행이나 장면을 바꾸는 것. 제품 코드는 주소를 읽지 않는다.
- 교사용 입구, 숨은 미리보기 주소, 점검용 전역 변수나 함수. 사용자가 "제작자가 정해 놓은 대로 게임을 한다"고 정했고, 숨은 미리보기 주소도 거절했다.
- 같은 기록을 여러 창에서 여는 것을 막는 장치(지금은 없다. 나중에 저장한 창이 이긴다).
- 점검용 로컬 서버가 `design/`과 `.git/` 경로를 내주는 것(서버가 403으로 막는다).

## 4. 남기는 기록

게임은 실행 중에 아무것도 기록하거나 보내지 않는다(분석 도구 없음). 기록은 제작과 점검 쪽에서 남긴다.

| 사건 | 남는 곳 |
| --- | --- |
| 화풍 승인, 낭송 목소리 승인과 노래별 배정 결정 | `docs/approvals.md`(날짜, 결정, 덧붙인 지시, 샘플 해시) |
| 낭송 조각 하나하나의 생성(모델, 목소리, 기준 음성 sha256, 줄 글, 자르기 방식, 받아쓰기 일치, 길이, sha256) | `assets/audio/voice/manifest.json` |
| 승인한 목소리의 고정(기준 음성 sha256, 설계 id) | `tools/voice/voices.json`의 `candidates.*.referenceSha256`·`voiceDesignId` |
| 그림 하나하나의 생성(프롬프트 파일, 원본 sha256, 크기·형식) | `assets/manifest.parts/art.json` |
| 국악 음원의 원곡·악구 번호·내려받은 날·공공누리 문구 | `assets/audio/CREDITS.md`, `tools/bgm/sources.json` |

| 노래마다 원문 출처와 확인 상태, 출처가 약한 자료에서 옮긴 사실 | 노래 데이터의 `citation`·`citationNote`·`verification`, `docs/글-확인-문서.md`의 '먼저 볼 출처 메모' |

## 5. 자격 증명: Fish Audio API 키

- **만들기**: 사용자가 Fish Audio 유료 계정(API 충전 이력이 있어야 상업 이용 조건을 채운다)에서 만든다. 무료 계정 키는 유료 모델 요청에 HTTP 402를 받는다. 도구는 돈이 드는 첫 요청 앞에서 계정이 유료 이용인지, API 충전액이 남았는지 확인하고 아니면 멈춘다(계정 번호와 금액은 기록하지 않는다).
- **보관**: `%LOCALAPPDATA%/yetnorae/fish.key` 한 곳. 저장소, 셸 설정 파일, 환경 변수 영구 설정, 다른 문서에 복사하지 않는다.
- **전달**: 명령 하나에만 환경 변수로 넘긴다: `YETNORAE_FISH_API_KEY="$(cat "$LOCALAPPDATA/yetnorae/fish.key")" python tools/voice/build_voice.py …`. 키 파일을 `cat`만 하거나 `echo`로 출력하지 않는다.
- **쓰기**: `tools/voice/build_voice.py`만 키를 읽는다. 도구는 키를 화면·기록·파일에 쓰지 않고 오류 글에서도 지운다. `--dry-run`·`--self-test`는 키 없이 돈다.
- **지출 한도**: 한 번 실행에서 `--max-usd`(기본 3 USD)를 넘을 요청은 보내지 않는다. 한도를 올리는 것은 사용자 승인 뒤에만.
- **회전과 폐기**: 낭송 제작을 마친 뒤 사용자가 Fish Audio에서 지금 키를 폐기하고 필요하면 새 키를 만든다(아직 하지 않았다). 키가 대화, 로그, 커밋, 파일 어디에든 드러났으면 바로 폐기한다.

## 6. 민감한 자료의 처리

- 학생 이름은 별명이어도 된다. 이름은 기록 목록과 결과 카드에만 쓰이고, 지우기 한 번(확인 한 번)으로 기록과 카드 자료가 함께 사라진다. 기기 간 이동이 없으므로 다른 기기에 남지 않는다.
- 출판사 이름은 저장소 안에서 다룰 일이 생기면 글자 번호로만 다룬다(점검 코드처럼). 커밋에 한 번 들어가면 이력을 다시 써야 하므로, 발견 즉시 커밋을 멈추고 사용자에게 알린다.
- 교과서 글을 그대로 쓰고 출판사 허락 전에 공개하는 것은 저작권 회색 지대 설명을 들은 사용자가 받아들인 위험이다. 공개는 사용자가 결정한다.
- 자산은 상업적으로 쓸 수 있어야 한다: 낭송은 Fish Audio 유료 API(이용약관상 유료 이용자의 상업 이용 허용), 배경음은 공공누리 제1유형(출처 표시), 그림은 Codex 이미지 생성으로 이 게임을 위해 만든 것, 글꼴은 SIL OFL 1.1(이름을 `Yetnorae Text`로 바꿈), Three.js는 MIT. 낭송 목소리는 실제 사람을 본뜨지 않고 글 설명만으로 설계했고, 출처 화면에 AI 합성 음성임을 밝힌다.
