# 승인 기록

제작 중 사용자가 확인하고 승인한 것을 남긴다. 원본 그림과 음성은 저장소에 올리지 않고(`assets/raw/`), 이 기록이 승인의 근거다.

## 화풍 (2026-10-05 승인)

- 결정: 아래 샘플의 화풍으로 나머지 그림을 만든다.
  - 종이 인형처럼 오려 겹친 한지 질감, 가는 먹선
  - 색은 한지 미색·먹·먹회색을 바탕으로 하고, 단청 녹청·주홍과 바랜 금색을 조금만 쓴다
  - 차분한 서고 분위기, 만화·애니메이션 느낌은 피한다
  - 그림 안에 글자를 넣지 않는다
- 덧붙인 지시
  - 기념품 물건은 실제 모양이 정확해야 한다. 샘플의 해금은 활과 줄의 구조가 틀려서 본 제작 때 모양을 더 엄격히 지시하고 확인한다.
  - 학생(견습 사서)은 두 가지 모습을 만들어 학생이 시작할 때 고르게 한다. 지금 샘플 한 가지와, 더 중성적인 모습 한 가지다.
- 생성 방식: Codex CLI 내장 image_gen. 도구는 `tools/art/gen.ps1`, 프롬프트는 `tools/art/prompts/style_*.txt`.

## 낭송 목소리 (2026-10-06 승인)

- 첫 후보(narrator-a, narrator-b)는 목소리 바탕은 좋으나 한국어 원어민 말투가 아니라는 의견이 있었다. 한국어 설명·한국어 예문으로 다시 설계하고 줄 단위로 읽힌 뒤 음보로 자른 두 번째 후보(narrator-a2, narrator-b2)를 승인했다.
- 노래의 화자에 맞춰 나눈다.
  - a2(차분한 30대 여성): 여성 화자가 분명한 노래. 가시리, 서경별곡, 동동, 정읍사, 동짓달 기나긴 밤을, 어져 내 일이여, 청산리 벽계수야, 규원가, 사미인곡, 속미인곡, 님이 오마 하거늘, 귀뚜라미 저 귀뚜라미, 나모도 바히 돌도.
  - b2(따뜻하고 낮은 50대 남성): 나머지 노래. 화자 성별이 분명하지 않은 노래도 b2로 둔다. 배정은 글 확인 문서에서 교사가 바꿀 수 있다.
- 빠르기: 노래마다 가장 긴 음보가 자연스럽게 들어가는 빠르기로 맞춘다(늘이거나 줄이지 않음).
- 서비스: Fish Audio 유료 API(상업 이용 가능). 키는 환경 변수로만 쓰고 저장소에 남기지 않는다.
