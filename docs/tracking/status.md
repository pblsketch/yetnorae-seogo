# 현재 위치

게임 전체(입구, 다섯 관, 작품 방 다섯, 보스, 엔딩, 결과 카드, 2D 그림 판, 자산, 출처 화면, README, 글 확인 문서, 점검 묶음)를 만들었다. 공개 전 남은 일은 대부분 사람이 확인해야 하는 일이다: 교사의 글 확인, 문학 교과서 수록본 교체, 낭송과 배경음을 귀로 듣기, 공개 결정.

## 점검 상태

- 전체 점검 목록(`tests/run-all.mjs`)에는 점검 37개가 있다.
- 마지막으로 끝난 전체 점검은 완주·화면 점검을 목록에 넣기 전의 35개를 모두 통과했다(35/35).
- 완주 점검(`check-playthrough`)과 화면 점검(`check-ui`)은 각각 혼자 돌려 통과했다. 완주: 휴대폰 844×390 3D 빗금 6분 4초, 크롬북 1366×768 3D 박자 두드리기 41분 45초, 태블릿 1180×820 강제 2D 3분 34초. 화면: 확인 487개.
- 37개를 한 번에 돌린 전체 점검의 통과 기록은 아직 없다.

## 남은 것 (먼저 할 것부터)

1. **37개 전체 점검 한 번에 통과**: `node tests/run-all.mjs`가 0으로 끝나는 실행 기록.
2. **교사 글 확인**: 교사가 `docs/글-확인-문서.md`의 새로 쓴 글과 `pending` 노래 43편의 원문·해독·풀이·출처를 대조한다. 확인한 노래부터 `verification: 'verified'`로 바꾸고 글 확인 문서를 다시 만든다. 출처가 약한 노래(향가 6편, 「논밭 갈아 김매고」)가 먼저다. 모든 노래가 `verified`가 되어야 공개할 수 있다.
3. **문학 교과서 수록본으로 바꾸기**: 교사가 문학 교과서 파일을 주면 「찬기파랑가」, 「정석가」, 「나모도 바히 돌도」, 「사미인곡」을 수록본 그대로 바꾸고, 교과서 대조 도구로 맞춘다. 연 나눔이 바뀌면 「정석가」 방의 연 번호와 낭송 조각도 다시 만든다.
4. **낭송 귀로 듣기**: 받아쓰기 일치가 0.6 아래인 줄 110개와 음절 비율로 자른 조각 81개를 사람이 듣고, 잘못 읽히거나 잘못 잘린 줄만 다시 만든다.
5. **배경음 귀로 듣기**: 아홉 곡의 이음매와 음량을 들어 본다.
6. **문구 검토**: 출처 화면, README, 결과 카드의 말을 교사가 확인한다.
7. **Fish Audio 키 폐기**: 낭송 제작이 끝나면 지금 키를 폐기한다.
8. **공개 결정**: 사용자 승인 뒤 GitHub 저장소 만들기, 올리기, Pages 켜기, README에 공개 주소 적기.
9. **출판사 협의**: 교과서 글 사용 허락과 출처 표기 방식.
10. **향찰 이체자 9자 글꼴**: Noto Serif CJK KR 같은 더 큰 원본 글꼴로 부분 글꼴을 만들면 기기 글꼴 대신 같은 글꼴로 그릴 수 있다(원본 내려받기는 사용자 승인 뒤).
11. **판 카드 다시 받기**: 판을 마친 뒤에도 판 카드를 다시 받을 화면(어디에 둘지 교사가 정함).
12. **쓰이지 않는 판정 경로 정리**: 진행 엔진의 보스 2단계 시각 입력(`tapMs`)과 `judgeRemixTap`·`REMIX_TAP_WINDOW_MS`, 그 점검 시험을 지운다.
13. **미뤄 둔 기능(지금은 하지 않기로 한 것)**: 기기 간 이어하기 코드, 오프라인 캐시, 여러 창 보호. 사용자가 다시 정하면 만든다.
14. **시리즈와의 연결**: 이 게임의 반응을 본 뒤 시리즈의 세로 화면 원칙 재검토. 「닿지 않는 마음」(사미인곡·속미인곡), 「장터의 가객」(사설시조) 같은 후속 게임과 노래·자산 공유.
