# 0001. 가로 전용 화면

## 배경
고전문학 게임 시리즈의 기존 작품들은 세로로 든 휴대폰을 한 손으로 조작하는 원칙을 따랐다. 이 게임은 시리즈에서 처음으로 3D 공간(관마다 한 화면짜리 디오라마)과 리듬 조작(낭송에 맞춰 두드리기)을 쓰고, 재기 화면은 왼쪽에 디오라마 반응, 오른쪽에 원문 두루마리를 함께 보여야 한다. 세로 화면에서는 건축과 형식의 대응(탑의 층, 정자의 계단)과 두루마리를 한꺼번에 담을 수 없었다.

## 결정
가로 전용으로 만든다. 세로로 들면 게임과 소리를 멈추고 "기기를 돌려 주세요"를 띄우며, 가로로 돌아오면 진행 중이던 단위를 처음부터 다시 낸다. 배치는 16:9 안전 상자 기준이고 휴대폰(약 2.2:1), 크롬북(1366×768), 태블릿(4:3, 16:10), PC에서 깨지지 않아야 한다. 탭 이동이 기본이고, 터치 기기에는 왼쪽 아래 떠다니는 조이스틱, 오른쪽 아래 상황 버튼 하나를 둔다.

## 다른 선택지
- **시리즈처럼 세로 한 손**: 3D 디오라마가 화면 위쪽 작은 띠로 줄어 건축이 형식을 보여 주는 장치가 힘을 잃고, 반반 재기 화면이 위아래로 쌓여 두루마리 글이 몇 줄밖에 보이지 않는다.
- **세로·가로 둘 다 지원**: 모든 장면(관 다섯, 방 다섯, 보스, 엔딩)의 배치를 두 벌 만들고 두 벌 다 점검해야 한다. 이 게임 규모에서 감당할 수 없었다.

## 결과
- 연구 자료의 세로 화면 권고와 '소리 꺼짐으로 시작' 권고는 따르지 않는다(이어폰 전제와 함께 대체됨).
- 화면 점검과 완주 점검은 가로 크기 세 가지(844×390, 1366×768, 1180×820)로 한다. 세로 배치는 만들지 않고 회전 안내만 점검한다.
- 시리즈의 세로 원칙을 다시 볼지는 이 게임의 수업 반응을 본 뒤 사용자가 정한다.
