# 개발 약속 (모든 작업 공통)

이 문서는 여러 사람이 동시에 만들어도 코드가 한 사람이 쓴 것처럼 보이도록 맞추는 약속이다. 데이터 형식과 모듈 사이의 약속은 `js/data/README.md`가 유일한 기준이다.

## 구조

- 빌드 없는 정적 웹 페이지다. 모든 스크립트는 ES 모듈(`import`/`export`)이고, 빌드·번들 도구를 쓰지 않는다.
- Three.js는 `vendor/three/`(0.186.1)에 있고 `import * as THREE from 'three'`로 부른다(`index.html`의 import map).
- 폴더
  - `js/core/` — 화면과 상관없는 엔진(저장, 진행, 판정, 소리, 박자, 사건 버스, 설정). **DOM과 `window`에 직접 기대지 않는다.** 저장소나 시계처럼 바깥에 기대는 것은 인자로 받아서 Node에서도 바로 시험할 수 있게 한다.
  - `js/world/` — 3D와 2D 그림 판의 공간, 카메라, 조작, 화면 방향, 반반 틀. 관 모형은 `js/world/wings/<관 id>.js`.
  - `js/measure/` — 재기 화면(두루마리, 접기, 두드리기, 빗금, 고유 동작, 감정서).
  - `js/play/` — 관 한 판 흐름과 서가, 바구니, 수첩, 일지, 도감 화면.
  - `js/rooms/` — 작품 방. `js/boss/` — 보스전. `js/story/` — 시작 화면, 입구, 엔딩, 설정 화면. `js/result/` — 결과 카드. `js/ui/` — 여러 곳에서 쓰는 화면 부품.
  - `js/data/` — 데이터만 둔다(노래, 관, 개념, 이야기 글, 수첩 글, 리믹스).
- 공유 등록 파일(`js/registry.js`, `js/data/songs/index.js`, `tests/run-all.mjs`, `index.html`, `assets/manifest.json`)은 각 작업이 고치지 않는다. 연결 단계가 등록한다.

## 모듈 사이의 신호

- `js/core/events.js`의 `on/emit`으로 신호를 주고받는다. 사건 이름은 `js/data/README.md`의 '사건' 절에 적힌 것만 쓴다. 새 이름이 필요하면 작업 보고에 적는다.
- 전역 변수를 만들지 않는다. 필요한 것은 import한다.

## 화면과 글

- 화면에 보이는 글은 모두 한국어이고, 교사 확인을 받을 글(대사, 설명, 해석 문장)은 코드가 아니라 `js/data/`의 데이터 파일에 둔다.
- 스타일은 모듈마다 `css/<모듈>.css`에 두고, 색은 `css/base.css`의 토큰(`--hanji`, `--meok`, `--nokcheong`, `--juhong` 등)만 쓴다. 단청색(녹청·주홍)은 상호작용할 수 있는 것에만 쓴다.
- 글자 크기는 `--text-scale`(1, 1.15, 1.3)을 따른다. 움직임 줄이기는 `#app`의 `reduce-motion` 클래스로 알린다.
- 터치 대상은 48px 이상. 화면은 16:9 안전 상자 기준, 높이는 `100dvh`, 노치는 `env(safe-area-inset-*)`.

## 금지

- 바깥 주소 요청(글꼴, 분석 도구, CDN 포함). 모든 자산은 같은 사이트에서 부른다.
- 진행이나 장면을 바꾸는 주소 인자, 교사용 기능, 점검용 입구. 점검은 점검 도구가 로컬 저장소에 직접 상태를 넣는 방식만 쓴다.
- 점수, 등급, 순위, 타이머, 게임 오버.
- 출판사 이름(코드, 주석, 데이터, 커밋 글 어디에도).

## 점검

- 점검 파일은 `tests/check-<이름>.mjs`이고 `node tests/check-<이름>.mjs`로 단독 실행된다. 실패하면 종료 코드가 0이 아니어야 한다.
- 화면 점검은 `tests/lib/server.mjs`(로컬 임의 포트)와 `tests/lib/browser.mjs`(설치된 Chrome, 바깥 요청·콘솔 오류 수집)를 쓴다.
- 엔진 점검은 `js/core/` 모듈을 Node에서 바로 import해 시험한다.
- 점검을 흉내 내 통과시키지 않는다. 처음부터 통과만 하는 점검이 아니라 실제 실패를 잡는지(음성 사례) 함께 확인한다.
